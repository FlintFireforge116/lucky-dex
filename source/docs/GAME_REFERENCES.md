## Source provenance and recovery constraints

The original 22 downloads came from retail screenshot publishers, the Emerald decompilation and a Voltorb recreation project. These are not all the same asset category. Exact winning URLs, output encodings, transformations and SHA-256 values are in `app/src/main/assets/arcade/authentic-v0200/manifest.json`.

The two Amie extraction pages and backgrounds page credit the retail X/Y game and their sheet submitters. They were inspected directly during recovery. The website changed its media paths; recovery uses `/media/assets/61/64165.png`, `/media/assets/61/64166.png` and `/media/assets/59/62308.png`, not obsolete guessed download URLs. Crops preserve source pixels and transparency. The extra backgrounds sheet is a collection of Amie room decorations, not a clean Tile Puzzle stage.

PokeAPI is a collection, not a guarantee that every default sprite is a retail rip. Its documentation discusses community-maintained Gen5-style sprites for newer National Dex entries. All 1–1025 normal/shiny PNGs are locally packaged, and no custom shiny official-artwork or AI-generated replacement was used. See `docs/ASSET_AUDIT.md` for the full missing-fidelity list.

The downloaded scene captures are static reference assets. Gameplay must draw its moving actors, controls, current score and active board separately; baked actors or score text in a source screenshot cannot be passed off as live state.

For Arcade actor display, 2,078 PNGs have been extracted using exact alpha-bound crops: all normal/shiny Pokémon 1–1025 and all 28 Unown forms. `arcade/sprites/actors/manifest.json` preserves the original URL/checksum, crop rectangle and output checksum. Every crop has been verified pixel for pixel against its original, with no resizing or repainting. The general app retains the original sprite canvases.
