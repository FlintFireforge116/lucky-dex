# XY Roaring Skies — Stage 1 (LuckyDex v0.69.353)

**Baseline:** User-confirmed successful v0.69.352 GitHub build. The source is pinned to the official PokémonTCG xy6 Git blob `5eab0c0148a5cb52dd7005628aa61c793ec0d930` within immutable upstream commit `90f27d0e14cefe48ccb2b8922a7a356b2fcf0072`. The generator obtains the raw file without the rate-limited REST API and verifies its exact Git blob SHA before producing the Android asset.

## Official printed catalogue and launch

- **112 authentic collector prints:** #1–110 plus separate alternate-art **#77a (Shaymin-EX)** and **#92a (Trainers' Mail)**, never substituted for the numbered prints.
- **147 attack occurrences, 15 Ability occurrences and 12 Ancient Trait occurrences** must be retained from canonical data. The generator fails if those counts, ordering, or source blob change.
- Register Roaring Skies `xy6` with full Classic card lookup, physical inventory projection, pack/set picker, 30-card deck builder, opponent selectable sets and Android boot script. Card images use the official `images.pokemontcg.io/xy6/` source; existing `xy6` booster art was already installed.
- Supported attacks reuse tested battle descriptors, including real hand draw, searching from the draw deck or Energy Zone, status and coin flips, optional switching, targeted Bench attacks, recoil, attack/retreat locks, Energy discards, type/field-count damage, and healing. Revive, Ultra Ball, Switch, VS Seeker, Energy Switch, Winona, Steven and matching Spirit Links reuse existing Trainer mechanics.
- Matching **Gallade, Latios and Rayquaza Spirit Links** are wired into Mega Evolution turn-ending exceptions, with autobuilder compatibility checks; never add useless Spirit Links without their exact corresponding Mega prints.

## Gating and next implementation batch

**This is a staged integration, NOT full battle implementation of 112 prints.** Every print is present for collection and inspection. Any print with an unimplemented ability, attack, Tool/Stadium effect, special Energy restriction or Ancient Trait remains `battleEnabled=false, deckEligible=false` with a printed-rule reason. The CPU cannot select those incomplete cards.

- **Δ Plus** requires an additional selectable Prize after a knockout **by damage from that particular Pokémon's attack**, without leaking hidden Prizes or awarding bonus Prizes for poison or other indirect KOs.
- **Δ Evolution** allows first-turn and same-turn evolution but must still honour legal evolution families and Mega evolution turn-ending conditions.
- **Δ Wild** provides -20 attack damage after Weakness/Resistance only against the four specified attacker's types.
- **Sky Field** allows an eight-Pokémon Bench for *both* players and mandates owner-controlled correct discard to five on Stadium removal; do not enable it as a visual-only effect.
- **Double Dragon Energy** requires Dragon-only attachment, two-unit all-type provision, correct energy-cost matching, and discard on incompatible recipients.
- Remaining unique attacks and 15 Ability occurrences (notably Shaymin-EX **Set Up**, Hydreigon-EX **Dragon Road**, Togekiss **Serene Grace**, Reshiram **Turboblaze**, Banette **Tool Concealment**, and Latios-EX **Fast Raid**) need the correct board, hand, and attack-timing handlers. They are not replaced with no-ops.
- The next patch should tackle the global/unique mechanics in groups, then run an independent card-by-card, AI and 30-card deck-quality audit before declaring all 112 prints complete.

## Validation

- `node --test tests/v07353-roaring-skies-stage1.test.cjs` verifies local registry and a synthetic set of safe/gated effects and official integrity contract. The official catalogue and deck coverage tests execute on CI after the generator downloads the pinned source, and intentionally skip when run offline without that data.
- The existing v0.69.333 cross-era deck-quality audit explicitly knows `xy6` is generated by the Android pipeline (as with `xy1`–`xy5`), rather than mistakenly treating the empty source placeholder as a broken previously populated catalogue.
- **A locally passing Node test is NOT a verified GitHub APK build.** Only report success after the user's Actions workflow is green.
