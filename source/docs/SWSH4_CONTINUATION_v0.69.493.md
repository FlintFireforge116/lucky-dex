# Vivid Voltage v0.69.493

202/203 playable prints. Ninjask and Shedinja are now enabled. Cast-off Shell is a hand-evolution trigger, uses a physical deck reference, permits optional choice, and checks current ability suppression and placement legality. Older BW6 Cast-off Shell (an Ability, unlike the DP6 Poké-Power) can also place this Shedinja. The modern Ninjask can select older Shedinja prints. Opening setup, ordinary hand/bench placement and shared deck/discard placement predicates exclude swsh4-66. Older Loose Shell, DP6 Cast-off Shell and Molting candidates also respect the predicate. Life Squeeze uses damage counters and respects counter/effect protection. Shared automatic deck builder adds one Shedinja to compatible Ninjask decks when a duplicate non-Fossil Item is available for substitution; it does not treat Shedinja as a standalone Basic. Manual deck inclusion is supported. Exhaustive bespoke historical placement paths and Android APK/device remain unverified. Dusknoir remains gated because all Special Energy effects must be disabled, not merely Energy cost provision.
