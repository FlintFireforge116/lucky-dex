# Celestial Storm v0.69.422 — first consolidated integration

All 187 canonical prints are included in the catalogue, including the four alternate arts. The generator enables 80 prints and gates 107 until missing or invalid mechanics are implemented. There are 232 printed attacks, 51 Abilities, 43 Trainer prints and 2 Special Energy prints. See SM7_CURRENT_GAP_LEDGER.md for each blocker.

The compact data is bundled with a fixed SHA256 and upstream Git blob ID. It does not require network access during normal preparation or APK generation. The set is wired into the central catalogue, set picker, deck builder and opponent pool. Exact text reuse and validated descriptors are conservative; subsequent outcomes and independent audit are still required. Rainbow Energy's hand-attachment counter is implemented for both print IDs. Lisia's Prism Star filter is supported.

Local SM7 preflight: 14/14 tests; 99 enabled printed attacks swept for each side. Pelipper Firefighting remains gated because its Energy discard descriptor incorrectly requires a matching opposing Energy to declare the attack. APK build not verified locally.
