# LuckyDex v0.40.13 Cosmetics Sources

The initial 30 sleeve images in `app/src/main/assets/cosmetics/sleeves/` are locally packaged LuckyDex-original artwork created for this release. They are not copies of official Pokémon, Pokémon TCG, or Pokémon TCG Pocket sleeve files.

The catalogue uses Pokémon/TCG/TCGP *themes* and progression names to organise rewards, but the shipped image files are original geometric/pixel-style LuckyDex designs so the feature works fully offline and does not mislabel invented art as an official asset.

The registry is intentionally data-driven: individual sleeve images can be replaced later with properly sourced licensed/reference assets without changing save IDs, achievement reward bindings, or player ownership.
