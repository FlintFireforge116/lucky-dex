# Dash asset sources — v0.34.0

## Active course artwork

The playable renderer now uses 59 native Pokémon Emerald assets in `arcade/dash/gen3/`, decoded from pinned pret/pokeemerald commit `731ad5bfd6e6f265508d0efcca0ba42f9dcf5881`. Primary and secondary tilesets, original palettes, native map assemblies, field-effect foreground grass and genuine animation frames are preserved. There are no painted or tinted course floors. Full provenance, source locations, classifications, footprints and hashes are in [DASH_GEN3_ASSETS.md](DASH_GEN3_ASSETS.md) and the JSON manifest.

The offline source cache contains 204 checksum-listed upstream files. `python scripts/build_dash_gen3_assets.py` reproduces all native PNGs and manifests; Pillow is required. `node scripts/build-dash-previews.cjs` renders all 18 preview PNGs from the same seeded course and renderer used in gameplay (Playwright and Chrome required). Preview seeds, distances and sections are bundled in `arcade/dash/gen3/previews/manifest.json`.

The existing Pokémon actor sprites remain unchanged. Only four original LuckyDex pixel UI assets (shadow, player ring, player marker and finish strip) and sparse canvas pixel effects remain active from the earlier Dash art system. Emerald graphics remain copyrighted Pokémon game artwork; they are bundled for this requested private fan project. They are not covered by the original-art CC0 grant below.

## Historical v0.33 artwork — retained, retired from the course renderer

The following inventory documents the supplied baseline assets. Its tinted course textures, generated obstacles, old berry and manually composed promotional panoramas are no longer used by the active course renderer or course selection. Retained files do not imply active use. The new manifest supersedes this historical inventory.

All gameplay files are local PNGs. No art is hotlinked. Rendering uses cached images and nearest-neighbor pixels.

## Downloaded reference / adapted route art

Source: [pret/pokeemerald general tileset](https://github.com/pret/pokeemerald/tree/master/data/tilesets/primary/general). Downloaded `tiles.png`, `metatiles.bin`, and `palettes/00.pal` through `15.pal` on 2026-10-09. Exact downloaded bytes are retained in `scripts/dash-source/`. These are Pokémon Emerald graphics, copyright their respective Nintendo / Game Freak / Creatures owners; the decompilation repository does not confer an independent redistribution license on game artwork. Used for this personal fan project as requested.

Adaptation: assemble metatile 281 for textured sand/path, 1 for verge, 30/31/46/47 for evergreen, 224 for boulder, plus Emerald machine/rail metatiles 305/308/328 for the Electric and Steel course obstacles. Remove matching underlying turf colors; tint selected themes; retain native pixel geometry. Fire course rock art now also derives from the Emerald boulder. Reproduce with `scripts/adapt-emerald-dash-assets.py` after `scripts/build-dash-pixel-assets.py`.

Pokémon actor sprites are unchanged from supplied v0.30.0 in `arcade/sprites/actors/pokemon/` (including shiny variants). [PokeAPI/sprites](https://github.com/PokeAPI/sprites) was investigated as requested; no replacement racer sprites were downloaded. Existing sprite manifests/attribution remain unchanged.

## Original art

Remaining tiles, irregular edge transitions, themed objects, double-chevron boost pads, props, pixel shadow/ring/cursor and finish strip are original programmatically authored pixel art, generated by `scripts/build-dash-pixel-assets.py`. Dash stamina pickups now reuse the already-packaged PokeAPI Oran Berry item sprite (`arcade/sprites/items/oran-berry.png`) instead of the former generated pickup art. New original artwork may be reused under CC0; that grant excludes all adapted Pokémon Emerald graphics and existing Pokémon/PokeAPI sprites.

Theme direction: meadow, volcanic ash, coastal boardwalk, power station, woodland, ice, training pass, toxic marsh, desert, highland, crystal route, deep forest, quarry, graveyard, summit, moonlit forest, rail yard, luminous grove. Object silhouettes differ as well as palettes.
