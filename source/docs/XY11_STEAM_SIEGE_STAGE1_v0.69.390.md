# Steam Siege XY11 — integration stage 1 (v0.69.390)

## Scope and upstream evidence

- Next chronological official expansion: Steam Siege (`xy11`), released 3 August 2016.
- Immutable upstream repository: `PokemonTCG/pokemon-tcg-data`, commit `90f27d0e14cefe48ccb2b8922a7a356b2fcf0072`, file `cards/en/xy11.json`, Git blob `22ea97ca00b595fe6b121494fd45dd65692deee6`.
- **116 distinct printed cards**, **161 printed attacks**, **18 printed Abilities**, **7 BREAK Pokémon**, and **12 dual-type prints including alternate art**. All printed cards must exist in the generated catalogue; coverage is separate from playability.
- The generator writes `data/classic/xy11-print-compact.json` (pinned source cache), `app/src/main/assets/tcg-classic-steam-siege.js`, and `docs/XY11_BUILD_COVERAGE.json`. Each print carries `battleEnabled`, `deckEligible`, and explicit reasons for unsupported mechanics.

## Integrated in this stage

- Full source-backed set registration: set picker, Classic card lookup, player deck pool, CPU opponent deck pool, Android WebView boot loader, build version `0.69.390`/code `7390`.
- Seven BREAK prints use the pre-existing prior-stage attack/Ability inheritance mechanism. Stage and evolution legality remain in force; BREAK prints do not magically become Basic Pokémon.
- New dual types are faithfully represented in `types`, without reducing the Pokémon to its first type. Attack costs retain the source print's energy symbols.
- Source-exact, shared effect mappings for simple attacks plus print-specific effects such as Yanmega BREAK Barrier Break, Steelix-EX optional Wild Edge boost/recoil, M Steelix-EX Canyon Axe bench damage, Jumpluff Solar Step counting *remaining Prize cards*, and selected targeted status, Energy discard, forced switch, and Fossil rules.
- Anorith's Restored Barrier is implemented as a live passive Weakness aura for Restored Pokémon only, with Ability suppression, both active and bench Weakness paths, and regression coverage.
- Armor Fossil Shieldon / Claw Fossil Anorith reuse the printed **bottom seven of physical deck** Restored search from Fates Collide. The automatic deck builder links their Items to their matching Pokémon; it does not add random orphan Fossils.
- Steelix and Gardevoir Spirit Links reuse the exact printed matching Mega Evolution no-turn-end exception; automatic deck selection requires the specific Mega Evolution line, not a generic Trainer fill.
- Sycamore reuses the existing printed discard-hand, draw-seven Supporter implementation.
- **No generic no-ops for unimplemented printed effects.** Unsupported Pokémon/Trainer prints remain in catalogue/collection but cannot be auto-included in battle decks. This deliberately includes Steam Up, Captivating Poké Puff and several yet-unmapped mechanics.

## Release verification contract

From `source/`, in this order:

```sh
python3 scripts/check-gradle-source.py --self-test
python3 scripts/preflight-xy10-release.py --full
python3 scripts/preflight-xy11-release.py --full
```

The XY11 `--full` step **must** retrieve or reuse the exact 116-card pinned catalogue, regenerate the runtime file, inspect all costs/types/Abilites, ensure at least 35 battle-ready prints and the 40 explicitly listed ready IDs, run real deck-builder checks, and fail on broken effect descriptors. The source-only preflight skips the mandatory catalogue tests and is **not a release green light**.

Gradle task chain `preflightXY11ContractForApk -> generateXY11ForApk -> auditXY11ForApk` depends on the completed Fates Collide audit and runs before APK asset merge. The source checker also rejects misquoted or missing Gradle test arguments.

## Current verification and next steps

Offline local source-only checks and 75/75 Fates Collide cross-release tests passed while preparing this patch. **The official XY11 generated-catalogue test and Android/GitHub APK build have not been run here**, because the local execution environment cannot fetch the external catalogue. Before pushing, run the **full** preflight from Termux; if it fails, do not push. This is a **first stage**, not a statement that all 116 prints have completed their gameplay implementation or independent card-by-card audit. The coverage JSON generated by the full preflight enumerates the remaining gated mechanics and should drive the next bulk implementation pass before the independent audit.
