# Dream World visual sources — v0.50.1

The Dream World polish pass uses original Pokémon Dream World screenshots as remote visual art, with the existing bundled LuckyDex SVG kept as the venue fallback.

- Dream World venue / Dream Bridge: https://archives.bulbagarden.net/media/upload/4/49/DW_Dream_Bridge.png
- Ice Cream Scoop playfield / Pleasant Forest: https://archives.bulbagarden.net/media/upload/6/6c/Pleasant_Forest.png
- Wailord Water Spout playfield / Sparkling Sea: https://archives.bulbagarden.net/media/upload/a/a6/Sparkling_Sea.png
- Minigame visual reference: https://www.smogon.com/ingame/guides/dw_guide

Pokémon character sprites remain the existing local LuckyDex arcade sprite assets so gameplay does not depend on remote character art.

- Pokémon Seek / Spooky Manor background: https://archives.bulbagarden.net/media/upload/8/85/DW_Spooky_Manor.png
- Pokémon Seek gameplay reference: https://bulbapedia.bulbagarden.net/wiki/Dream_World_mini-games
