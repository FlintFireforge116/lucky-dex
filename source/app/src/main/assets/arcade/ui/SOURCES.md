# Arcade UI source notes

- `mystery-gift.svg` is a small transparent redraw/adaptation for LuckyDex inspired by the 18×18 Friend Gift bag sprite from *Pokémon Mystery Dungeon: Gates to Infinity* (Bulbagarden Archives: `MDBag_Gift_Sprite.png`). It is not a direct binary copy; it is used as a subtle in-puzzle Mystery Gift marker.
