LuckyDex v0.69.123 — Founja Jungle (SNAPFOUNJA) Classic TCG integration

WHAT THIS PATCH DOES
- Makes the 86 Founja Jungle card identities battle-enabled with printed HP, costs,
  attacks, abilities, Trainer text and attack/action descriptions from the
  creator's SNAPFOUNJA-v1 image archive.
- Adds the set to the Classic deck catalogue, manual filters, auto-builder set
  selectors, and CPU-only set pools.
- Implements Founja-specific Stadium, Tool, Ability and attack effects, with
  explicit handling for attack choices, dynamic damage, protections, and KO rules.
- Keeps the existing Florio and Classic battle fixes, Android Back navigation,
  and single-screen mobile Test Lab from v0.69.122.

HYBRID CLASSIC30 ENERGY CONVENTION
- Basic Energy generated by LuckyDex lives in the ordered Energy Zone; printed
  requests to obtain Basic Energy from the deck use that Zone, respecting its
  current next-card order. Basic Energy returned to hand remains playable there.
- Special Energy remains an actual deck card.
- Founja Jungle doubles Basic Energy attached to qualifying Grass/Darkness
  Pokémon; it does not create extra Energy cards.

ARTWORK
- This is a source-only code patch. The 86-card artwork pack is separate and is
  already published in the LuckyDex Lental GitHub release as
  luckydex-set-SNAPFOUNJA-v1.zip. Install that art pack using the app's existing
  artwork flow if those card pictures are not yet installed on your device.

CHECKS
- 86/86 Founja cards enabled and 99 attacks inspected/executed under synthetic
  combat setups, including choice-based attacks.
- 12 Founja-only AI battles completed without engine errors or stalled choices.
- 42 focused Classic regression tests passed (including the 13 new tests).
- JavaScript syntax checks passed.

LIMITS
- Automated battle simulations cannot guarantee perfect fidelity to every
  corner-case card interaction or on-device Android drag/tap behavior.
- User-facing strings preserve printed card text; where necessary, actual
  gameplay maps Basic Energy deck searches to the hybrid Energy Zone.
