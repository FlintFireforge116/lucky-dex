# LuckyDex

LuckyDex is an Android WebView Pokémon collection, Adventure and Arcade app.

The canonical build source lives unpacked in [`source/`](source/). GitHub Actions and local Android builds should build directly from that directory; release APK/source ZIP files are delivery artifacts and are not canonical repository inputs.

See [`source/README.md`](source/README.md) for build/test guidance and [`source/docs/RELEASE_HISTORY.md`](source/docs/RELEASE_HISTORY.md) for historical release notes.
